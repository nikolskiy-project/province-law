# PROVINCE LAW · Правовой навигатор

Статический сайт в компактном тёмном стиле ReConfig для **GitHub Pages**. Ищет пункты по обычным словам, фразам, опечаткам, сокращениям и суммам неоплаченных штрафов. Документы: **КоАП РП**, **ПДД РП**, **УК РП**, **ФЗоП РП** (игровые нормативные тексты MTA Province).

## Быстрый запуск

1. Распакуйте архив и **откройте `index.html`** в браузере — всё работает даже без сервера и интернета, так как индекс поставляется в `data/laws.js`.
2. Введите «поворотник», «доккументы», «парава», «встречка», `КоАП 8.1` или сумму задолженности, например `70000`, `70 000`, `70.000`, `70 000 штрафов`.
3. Используйте фильтры документов, независимое раскрытие карточек, копирование короткой команды `say`, сортировку и ссылки на форум.

Включён **локальный каталог из 150 записей**. Это не полный текст всех норм: карточки содержат краткие описания и ссылки на первоисточники.

**Автоматического обновления нет.** GitHub Actions не используется, сайт полностью статический. Если в старом репозитории уже лежит `.github/workflows/update-laws.yml`, **удалите этот файл в GitHub**, иначе прежнее расписание останется активным. В этой версии обновление правовых данных не запускается.

## Размещение на GitHub Pages

1. Загрузите папки `assets`, `data`, файл `index.html` и остальные файлы проекта в корень ветки `main`.
2. В **Settings → Pages** выберите **Deploy from a branch → main → /(root)** и сохраните.
3. Откройте сайт: запросы обрабатываются локально, ничего подключать в Actions не требуется.

Для запуска локального HTTP-сервера (необязательно):

```bash
python -m http.server 8000
```

Откройте http://localhost:8000/.

## Как работает поиск

Индексирование формулировок, описаний и тегов; нечувствительность к регистру и «ё»; синонимы (например, `кирпич`, `запрещающий знак`, `под кирпич` → нарушение требований знаков), опечатки; подсветка совпадений; ранжирование по соответствию названию, описанию, тексту; прямой поиск `КоАП 8.1`, `ПДД 9.1`, `УК 5.8`, `ФЗоП 4.8` или `8.1`. Вкладки ограничивают выдачу выбранным нормативным документом. Поиск выполняется целиком в браузере, без серверной передачи запросов.

### Поиск по сумме неуплаченных штрафов

Введённые `70000`, `70 000`, `70.000`, `70,000`, `70 тыс.` и `70 000 штрафов` обрабатываются одинаково. Числовой запрос **по умолчанию означает общую сумму задолженности по штрафам**, а не размер назначаемого наказания. Например, `70000` находит **КоАП 17.5**: неуплаченные штрафы **от 50 000 до 100 000 ₽**. Взыскание по самой статье составляет 50 000 ₽ и не участвует в выборе статьи.

- **17.4 КоАП** — задолженность от 10 000 до 50 000 ₽, назначаемое наказание 30 000 ₽.
- **17.5 КоАП** — задолженность от 50 000 до 100 000 ₽, назначаемое наказание 50 000 ₽ и лишение прав на один год.
- **17.6 КоАП** — задолженность строго более 100 000 ₽, назначаемое наказание 100 000 ₽ и лишение прав на два года.

На ровных границах диапазонов выводятся все подходящие записи: 50 000 ₽ удовлетворяет буквальной записи диапазонов как 17.4, так и 17.5. Для поиска именно **по назначаемому наказанию** отдельно укажите `наказание 30000` или `размер штрафа 50000`.

При нажатии «Копировать» в буфер помещается только короткая игровая фраза `say 17.5 управление транспортным средством с неуплаченными штрафами на общую сумму от 50.000 до 100.000 рублей`. Каждая карточка открывается и закрывается независимо. В расширенной части есть текст статьи и готовая фраза. Числовой разбор работает и с импортированными актуальными текстами: он берёт диапазон **из описания состава нарушения до санкции**, а не из самой санкции.

### Установка этого обновления

Патч-архив содержит только изменённые файлы. Распакуйте его и замените одноимённые файлы в своём репозитории. База из предыдущего обновления (с КоАП 17.4–17.6) остаётся прежней.

**Важно: для полного отключения автообновления удалите в уже существующем репозитории `.github/workflows/update-laws.yml`.** ZIP-патч не может удалить файл, который уже лежит у вас на GitHub. Его можно удалить через интерфейс GitHub (откройте файл и выберите Delete file) или командой `git rm .github/workflows/update-laws.yml`.

## Выделение текста

По образцу `rehub.css` оригинального ReConfig поля ввода и код можно выделять: выделение фиолетовое (`rgba(139,92,246,.58)`), текст белый, а курсор остаётся фирменным.
